# StudyCalc and Web UI Prototypes

This folder contains a collection of static HTML pages and front-end prototypes built as a small web app playground. The files combine calculator-focused interfaces, a signup form, a maze game, and a secure portal/cipher-style demo.

## Project overview

The project appears to be a collection of experimental front-end pages for a student study / productivity app, with several variations and mockups created over time. Most files are standalone HTML pages that can be opened directly in a browser.

## File list and purpose

- `index.html`  
  Main dashboard-style page with a calculator-like UI and a study/workspace layout.

- `calculator code.html`  
  A calculator dashboard with a more detailed interface, calculation history, and PDF export logic.

- `New code of calc.html`  
  Another calculator/prototype version with a sidebar layout, upgrade modal, and trial-counter experience.

- `signup.html`  
  Registration/signup form with password visibility toggle, verification section, terms checkbox, and styled account creation page.

- `Untitled-1.html`  
  Brain Teaser Maze game with difficulty levels, a restart button, keyboard-style movement logic, and a goal condition.

- `Untitled-1.fire wall.html`  
  Secure portal / cipher demo with tabs, alerts, captcha-style verification, and a hidden output area.

- `Untitled-2.html`  
  Duplicate/variation of the secure portal/cipher design, likely a second iteration of the same concept.

- `Untitled-3.html`  
  Firebase setup/testing page that imports Firebase SDK modules and logs app initialization to the browser console.

## Main features

- Calculator interfaces and math-related screens
- Student dashboard / productivity app styling
- Account registration page with validation-style UI
- Maze game with selectable difficulty
- Secure messaging / encryption portal mockup
- Firebase integration test harness
- Pure front-end HTML/CSS/JavaScript implementation

## How to run

Because these are static HTML files, no installation is required.

1. Open the folder in a browser.
2. Open any `.html` file directly in your browser.
3. If a page depends on JavaScript, make sure browser scripts are enabled.

Examples:

- Open `index.html` for the main dashboard mockup.
- Open `signup.html` for the registration page.
- Open `Untitled-1.html` for the maze game.
- Open `Untitled-3.html` for the Firebase test page.

## Notes

- This project is front-end only and does not include a backend or database.
- Several files are duplicate or alternate versions of the same idea, which suggests the folder was used for experimentation and UI iteration.
- The code is best suited as a prototype/demo rather than production-ready software.
